Three focused modes

Choose the job. Start the clock.

Inside Edge Timing keeps each workflow clear: build and run workouts in Intervals Timer, capture training splits in Splits Timer, or record race finishers in Race Timer.

Intervals Timer

Structured sessions that go beyond a basic work/rest timer.

Create full training sessions from named sets. Each set can have its own interval count, work duration, recovery duration, set rest and audible beat pattern.

  • Build sessions such as 4 x 45/45, rest, then 6 x 30/30
  • Chain as many sets as the session needs
  • Use steady beats, faster beats or slower beats inside work intervals
  • Switch live beat prompts between 1s, 5s, 10s, Faster, Slower and Off
  • See current set, interval count, next interval and total session progress
  • Save completed workout reports with effort score, notes and export

Splits Timer

A coach-friendly stopwatch for training repetitions.

Use Splits Timer when you need a clean stopwatch with repeated captures: laps, drills, flying efforts, repeated starts or groups crossing a marker at different times.

  • Large digital or analog stopwatch display
  • Capture split and cumulative time
  • Add quick notes to recorded splits
  • Save and share completed split sessions
  • Designed for iPhone and iPad use at rinkside, trackside or courtside

Race Timer

Finish-order recording for real event pressure.

Race Timer is built for the practical manual timing situations many clubs still rely on: start the race, tap each finisher, add race numbers, then save or share the result before the next race rolls around.

  • Record 1st, 2nd, 3rd and later finishers in order
  • Show total race time and gap to the winner
  • Store competition, date and race number with every race
  • Auto-fill skater details from a cached race-number list where available
  • Manual fallback for late entries, guest skaters or roster changes
  • Save races locally, auto-advance race numbers and export race or competition history

Short track at its core

Inspired by the reality of the ice, useful far beyond it.

Short track training asks for repeat efforts, precise timing, changing intensity, loud environments and fast decisions. A useful timing app has to be readable at a glance, quick under pressure and forgiving when a session changes in the moment.

Inside Edge Timing starts there: big countdowns, clear phases, audible cues, live progress, quick stopwatch controls and a race workflow that respects the pace of a competition day.

The same tools work naturally for strength circuits, HIIT, cycling, running, rehabilitation, mobility, team-sport conditioning and custom training sessions.

Training intelligence

More context without turning the app into admin.

Heart rate

Live Bluetooth HRM support

Connect a compatible Bluetooth heart-rate monitor and view live BPM during training. Enter your lactate-threshold heart rate so the app can show personalised LTHR zones.

Zones

LTHR-based effort guide

See Active Recovery, Endurance, Tempo, Sweet Spot, Lactate Threshold, VO2 Max and Anaerobic Capacity ranges calculated from your own threshold value.

History

Workout and race records

Save interval completion reports, split sessions and race results locally. Add effort scores and notes, then share reports through the standard iOS share sheet.

Race-day workflow

Built for the two-minute gap before the next race.

  1. 01

    Prepare the event

    Enter the competition name and date once. Race Timer keeps that context available while you move through the programme.

  2. 02

    Start and capture

    Start the clock, then tap Record Finisher as each athlete crosses the line. The app keeps finish order, total time and gaps together.

  3. 03

    Add skater details quickly

    Type the race number and, where the cached roster matches, the app fills in name, category and club. You can still edit manually at any time.

  4. 04

    Save and move on

    Save the race, let the race number advance, then share a single race or export the wider competition group when needed.
